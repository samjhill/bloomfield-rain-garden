# Bloomfield Rain Garden Project

A single-page static website showcasing a real-world rain garden project built in Bloomfield, NJ. The site serves as a visual demonstration of the project for neighbors and the township, and as a public educational resource and template for building similar compliant gardens.

## 🌿 About

This website documents a rain garden project designed to reduce runoff, support native biodiversity, and comply with Township code:
- Max plant height: 2.5 ft
- No encroachment onto the curb/gutter
- Must be maintained in a safe and clean manner

## 📋 Features

- **Educational Content**: Explains what rain gardens are and their benefits
- **Impact Statistics**: Highlights the environmental impact of the project
- **Native Plant List**: Comprehensive list of plants organized by moisture zones
- **Project Photos**: Visual documentation of the installed garden
- **Printable Resources**: Links to downloadable signs and guides
- **Mobile Responsive**: Fully responsive design that works on all devices

## 🚀 Getting Started

### Local Development

1. Clone the repository:
```bash
git clone git@github.com:samjhill/bloomfield-rain-garden.git
cd bloomfield-rain-garden
```

2. Open `index.html` in your web browser, or use a local server:
```bash
# Using Python
python3 -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server

# Using PHP
php -S localhost:8000
```

3. Visit `http://localhost:8000` in your browser

### Deployment

This site is deployed via GitHub Pages. To deploy:

1. Ensure your repository is public (or you have GitHub Pro for private repos)
2. Go to Settings → Pages
3. Select source: Branch `main` / Folder `/ (root)`
4. Save

Your site will be live at: `https://samjhill.github.io/bloomfield-rain-garden/`

## 🔧 Customization

To customize the site:

1. **Update Content**: Edit `index.html` directly
2. **Change Styling**: Modify `style.css`
3. **Add Images**: Place images in `assets/` directory and update references
4. **Add PDFs**: Add PDF files to root directory and update links
